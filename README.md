# Screenshot Comparison Framework

## Navigation
test - code for testing
utils - code with image utils and more
core - WebDriver and opencCV comparator;
notebooks - Jupyter notebooks with graduate work about classification defect or unsbable screenshoots
screenshoots - folder with actual and expected screenshots
reports - result of the test report

## Features
- ✅ Selenium WebDriver automation
- ✅ OpenCV-based image comparison
- ✅ Perceptual image hashing
- ✅ Automatic baseline creation
- ✅ Visual diff highlighting
- ✅ HTML reports
- ✅ Full page screenshots
