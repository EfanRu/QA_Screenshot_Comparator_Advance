## README для файлов дипломной работы по созданию модели для классификации дефектов и нестабильных скриншотов при регрессионной проверке UI через автотесты

### Files:
- notebooks/:
  - Intro.ipynb вводная информация, экономическое обоснование, датасет и ограничения;
  - Prepare_dataset** подготовка дата сета. Для классической модели нахождение разница и отбрасывание 
  нулевых элементов. Состоит из файлов:
    - Prepare_dataset.ipynb - исходная подготовка данных;
    - Prepare_dataset_3_other_domain.ipynb - подготовка данных для другого домена;
    - Prepare_dataset_increase_ds.ipynb - подготовка данных для увеличенного дата сета;
  - Classic_model** исследования классических моделей. Извлечение и выбор признаков, обучение, подсчет метрик, 
  анализ результатов. Состоит из файлов:
    - Classic_model.ipynb - первоначальный расчет;
    - Classic_model_2_increase_ds.ipynb - увеличенный дата сет;
    - Classic_model_3_other_domain.ipynb - проверка другого домена;
    - Classic_model_4_choose_model - выбор лучшего алгоритма.
  - NN** исследования нейросетевых моделей. Создание архитектуры или загрузка уже готовой, обучение и подсчет метрик, 
  анализ результатов. Состоит из файлов:
    - NN.ipynb - первоначальные исследования с предобученной моделью MobileNet_V2;
    - NN_2_increase_ds.ipynb - увеличенный дата сет;
    - NN_3_clear_model.ipynb - пробуем создать свою модель;
    - NN_4_micro.ipynb - пробуем создать микро модель без переобучения;

```commandline
PS> Можно было бы избежать большого дублирования кода, но я специально сделал дубли файлов, чтобы сохранить историю 
и не делать ноутбуки слишком длинными файлами.
```
